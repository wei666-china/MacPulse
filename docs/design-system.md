# MacPulse 设计规范「玻璃仪表」(v3)

2026-08-12 定稿。审美目标一句话:**高级、简洁、真科技感**——
精密仪器的克制,不是霓虹气泡的热闹。网络页是本规范的参照基准。

## 三条铁律

### 1. 透明是身份

面板底层是 `behindWindow` 系统材质(BehindWindowBlur.swift),直接透出
桌面墙纸;卡片是玻璃上的第二层玻璃(官方 `glassEffect`)。**任何一层都
不准刷实色底、不准放彩色光斑、不准给玻璃叠自定义描边或投影**——
层次感由系统材质自己给,叠妆立刻露出非原生感。
(无障碍例外:减弱透明度用户得到实色底,增强对比度用户得到边框。)

### 2. 色彩只表达状态,装饰层全单色

- 语义色仅三个:`normal`(好,绿)、`warm`(注意,橙)、`critical`(出事,红)。
  **除此之外整个界面没有彩色**
- 装饰与序列区分一律用墨阶(`ink` 0.85 / `inkSoft` 0.45 及派生深浅,
  亮暗自适应):同一色相靠深浅分层,占用越「硬」颜色越重
- 系统控件(分段选择器/开关)全局 `.tint(.primary)` 石墨化
- 否决记录:「跟随系统强调色」方案 2026-08-12 被否——默认蓝廉价感
  (Wei 原话「丑到爆」);彩虹行图标更早被否(「没主题」病根)
- 发光、辉光、彩色阴影:禁

### 3. 数字是仪表读数

- 一律 `monospacedDigit`,大数用标准 SF semibold(**不用 rounded**——
  圆体亲切有余,仪器感全无)
- 读不到就是「不可用」/「本机型不提供」,永远不显示假 0(全 App 铁律,
  设计层同样遵守:空态不许用装饰填充)

## 组件词汇表

| 组件 | 用途 | 关键约束 |
|---|---|---|
| `LiquidCard` | 唯一的卡片容器 | 系统玻璃,禁叠妆 |
| `SectionHeader` | 卡内标题 | headline + 右侧 caption 副题 |
| `ValueRow` | 标签-值行 | 图标单色;值 semibold 等宽 |
| `MetricCard` | 宫格大数卡 | 图标单色圆底;量表色=语义进度色 |
| `StatusPill` | 状态胶囊 | 色=状态语义色,唯一允许的彩色标签 |
| `PowerRailRow` | 功率条 | nil 画虚线空轨,不画零宽实条 |
| `BehindWindowBlur` | 透桌面底 | .popover 材质,始终 active |

## 复审清单(改动 UI 时自查)

- [ ] 有没有新增装饰性颜色?(只许语义色和系统强调色)
- [ ] 有没有给玻璃叠描边/阴影/渐变?
- [ ] 大数字是不是 monospacedDigit 且非 rounded?
- [ ] 空态是不是如实「不可用」而不是 0 或装饰?
- [ ] 亮/暗外观、减弱透明度、增强对比度三种模式都过了吗?
