## 总览 —— 已改(本次动刀)

病灶:有数字没判断、有重复没重点。CPU/内存宫格是性能页数字的复读;
首屏最该有的「谁在耗电」「充电结论」反而缺席。

处方(已实施):
- 英雄卡保留(电池环+净功率+续航+三脚注,骨架是好的)
- 新增**警示条**:只在真有事时出现(热点 ≥95°C / 系统热压力 / 健康度 <80%),
  平时不存在——安静是常态的特权
- 新增**充电结论卡**(插电时):充电链路判定的一句话版,细节去电池页
- 新增**谁在耗电卡**:能耗前三的进程组 + CPU/内存/整机功耗三脚注,
  首屏第一次让数字后面有名字
- 四宫格砍成两宫格(芯片热点、SoC 总功耗——这两个性能页外无处可看)
- 实时能量图保留
